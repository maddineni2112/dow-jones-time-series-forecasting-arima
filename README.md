# Dow Jones Time-Series Forecasting with ARIMA

**Timeline:** February 2026  
**Category:** Main project

This project analyzes Dow Jones time-series behavior and develops ARIMA/SARIMA forecasting workflows. It uses stationarity checks, ACF/PACF diagnostics, STL decomposition, and forecast visualization to compare time-series modeling choices.

## Stack

R, forecast, tseries, ggplot2, lubridate, ARIMA, SARIMA, STL, ADF, ACF, and PACF.

## Repository contents

- `src/project3_code.R`, `src/demo.R`, and `src/TS.R` — modeling workflows.
- `data/` — small train/test extracts used for reproducibility demonstrations.
- `reports/` — project report.
- `data/README.md` — provenance and full-data instructions.
